# OpenAPI

OpenAPI 3.x specifications for HTTP-based LMS contracts.

No specs yet — the first adapter (ProgressMe/Edvibe) uses WebSocket, documented
in [`../asyncapi/`](../asyncapi/).

Future HTTP-based adapters (ClassIn, Canvas, Tutor LMS Pro, LifterLMS,
LearnDash, Moodle, SCORM Cloud) will define their OpenAPI specs here.
